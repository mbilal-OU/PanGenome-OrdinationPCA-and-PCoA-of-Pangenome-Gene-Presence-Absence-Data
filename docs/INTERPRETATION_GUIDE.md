# Interpretation Guide

1. Check explained variance in `results/pca/pca_explained_variance.tsv`.
2. Check the labeled PCA plot in `figures/PCA_labeled_genomes.png`.
3. Check top loadings in `results/loadings/top_PC1_loadings_annotated.tsv`.
4. Check gene patterns in `results/loadings/top20_PC1_presence_absence_with_header.tsv`.
5. Compare with metadata.
6. Compare with phylogeny.
7. Avoid overclaiming. PCA generates hypotheses, not proof of mechanism.
